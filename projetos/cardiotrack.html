CardioTrack — IoT heart monitoring, end to end

Firmware on ESP32, a Go backend and a Flutter app, deployed with Kubernetes.

UFSC2026 See the code
3layers built solo

The problem

Heart-rate data from a wearable sensor is useless until it survives the trip from the device to a screen someone reads.

What I built

I built the whole path: firmware in C++ on an ESP32, a scalable backend in Go, and a Flutter app, integrated through Kubernetes.

Result

A working end-to-end system, and the project where I owned every layer myself.
