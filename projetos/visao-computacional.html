Visual contaminant sensor — computer vision

A visual sensor that measures how much contaminant is mixed into waste on a conveyor.

UFSC2026 See the code
3contaminant classes

The problem

On a pyrolysis/HTC plant conveyor, plastic, styrofoam and inert material get mixed into the organic matter, and nobody measures how much.

What I built

Computer vision treated as a data pipeline, not magic: frame → YOLO detection → contaminant area → rule → FastAPI. An RGB pixel matrix becomes structured records (JSON/SQL with coordinates and classes) that trigger automations.

Result

Unstructured images turned into a number an operator can act on, with the alert already wired.

Stack

  • Python
  • YOLO
  • FastAPI
  • SQL
  • OpenCV
