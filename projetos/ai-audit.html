Audit of a document-classification AI agent

A pipeline that re-reads 4,754 records with Gemini and turns “we think it works” into a number.

Franq Open Banking2026

The problem

An AI agent was reading customer documents in production and nobody could say how often it was right, or which document type it struggled with.

What I built

A Python pipeline joining BigQuery and Gemini 2.5 Flash: it pulls the agent’s verdicts, re-reads the same documents and compares field by field. Stratified sampling keeps rare document types in the measurement.

Result

4,754 records audited end to end, with accuracy broken down by document type — the input that decides where to improve the agent first.

Stack
