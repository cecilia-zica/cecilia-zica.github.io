Parallel cellular automata in C — 33.9× speedup

Pthreads with fixed row bands and barrier synchronisation, measured on the Santos Dumont supercomputer.

UFSC · INE56452026 See the code

The problem

A sequential cellular-automata simulation took long enough that the experiment itself became the bottleneck.

What I built

In a team of students I owned the main version — the static one: fixed row bands per thread and barrier synchronisation, plus I/O optimisations. Everything validated by 28 automated tests.

Result

33.9× speedup over the reference sequential version, measured on the Santos Dumont supercomputer.
