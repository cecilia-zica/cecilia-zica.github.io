Delivery management backend

A Python backend modelling deliveries, residents and status, with SQLite persistence.

The problem

What I built

A backend applying object-oriented principles: entities for delivery, resident and status, persistence in SQLite and the rules that govern each transition.

Result

A small operations domain modelled properly — the same reasoning a logistics flow asks for at scale.
