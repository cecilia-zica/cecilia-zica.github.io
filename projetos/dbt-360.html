Analytics engineering

360° analytics base in dbt

Multiple sources consolidated into one view of individuals and companies, feeding ML models.

The problem

Customer data was spread across sources with different grains and no agreement on what a missing value meant.

What I built

An analytics base in dbt and SQL consolidating the sources into a 360° view of individuals and companies, including CNAE and Serasa data, with documented grain, tests and a data dictionary.

Result

One agreed source for customer questions, now used by Machine Learning models and by the product dashboard.
