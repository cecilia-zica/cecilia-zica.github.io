Partner request triage with agent orchestration

Two agents read free-text requests, classify urgency and name what is missing before a human opens the queue.

Franq Open Banking2026
2agents in the chain
3decisions per request

The problem

Partner requests arrived as free text. Someone had to read every one to know the category, the urgency and whether it was even actionable.

What I built

An orchestration in Python: the first agent classifies category and urgency; the second checks the request against what the process requires, names the missing information and suggests the routing.

Result

The queue reaches a human already triaged, with the gap in each request named — the back-and-forth with the partner starts one step ahead.
