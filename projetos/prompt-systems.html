The problem

Every repeated task started as a new prompt. Same request, different wording, different result — and what worked stayed buried in an old chat.

What I built

I stopped writing prompts and started saving instructions. Each task I repeat has a file: the writing and visual standard for a deliverable, how to document a process, how to validate a report. I call the file by name and the model already knows the format, the limits and what counts as done. Two kinds live in the library: skills, which produce something to a fixed standard, and review agents, which check work — a validator that reads an event-mapping report against the product playbook and the dbt macros, and a panel of five reviewers that each take one angle and must justify every deduction.

Result

A repeated task is now one call instead of a prompt written from scratch. The result does not change with who asked, and fixing the rule once fixes every run after it.
