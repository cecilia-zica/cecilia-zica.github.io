Sinuca Sítio Champ — tournament app

Live scoreboard, single-elimination bracket and a cinematic podium reveal.

Personal2026 See the code
8players in the bracket

The problem

An eight-player pool tournament falls apart when the bracket lives on a napkin.

What I built

A Next.js app to run and reveal the tournament: live scoreboard, bracket from quarters to final, and a podium reveal with scenes and transitions built in pure CSS and SVG. The bracket is saved in the browser, so it survives a refresh mid-tournament.

Result

A tournament run end to end without a spreadsheet, and state that never got lost.

Stack

  • Next.js
  • React
  • TypeScript
  • CSS/SVG
